📡 วิธีเรียก UCR Smart City Data API

คู่มือนี้สำหรับ อีกโปรเจกต์ ที่อยากดึงข้อมูล survey (รายงานที่ผู้ใช้ส่งผ่าน LINE chatbot) ออกจากระบบนี้ — เขียนแบบสมมติว่าคุณ ไม่เคยรู้จัก JWT มาก่อน เลย

⚠️ สิ่งแรกที่ต้องเข้าใจ

API นี้ เปิด URL ในเบราว์เซอร์เฉยๆ ไม่ได้ เช่นพิมพ์ https://your-host/api/dashboard/reports ลงช่อง address แล้วกด Enter → จะได้ 401 Unauthorized (ไม่ผ่าน)

เพราะทุก endpoint ต้องแนบ "บัตรผ่าน" (JWT token) ไปกับคำขอ ในส่วนหัว (header) ชื่อ Authorization เสมอ ดังนั้นต้องเรียกผ่านโค้ด (Python / Node / curl) ไม่ใช่ช่อง address ของเบราว์เซอร์

JWT คืออะไรสั้นๆ: บัตรผ่านที่ปลอมไม่ได้ ข้างในเขียนว่า "คุณคือใคร สิทธิ์อะไร หมดอายุเมื่อไหร่" เซ็นด้วยรหัสลับ (SECRET_KEY) ที่สองฝั่งรู้ร่วมกัน ฝั่ง API ตรวจลายเซ็นแล้วถึงยอมให้เข้า

ภาพรวม 3 ขั้นตอน

ขั้น 1. ขอ SECRET_KEY จากเจ้าของระบบ (รหัสลับที่ใช้เซ็นบัตร)

ขั้น 2. สร้าง JWT token ขึ้นมาเอง 1 ใบ (เซ็นด้วย SECRET_KEY นั้น)

ขั้น 3. เรียก API โดยแนบ token ใน header Authorization: Bearer <token>

ขั้น 1 — ขอ SECRET_KEY

ระบบนี้ไม่มีหน้า login และไม่มี endpoint แจก token — คุณต้องสร้าง token เอง โดยใช้ SECRET_KEY เดียวกับที่ฝั่ง API ใช้ตรวจ

ความลับสุดยอด: ใครรู้ SECRET_KEY = สร้างบัตร admin ปลอมได้ ห้ามเอาไปแปะในโค้ดฝั่งเบราว์เซอร์ / ห้าม commit ลง git / เก็บใน .env ฝั่งคุณเท่านั้น

ขั้น 2 — สร้าง JWT token

token ต้องมีข้อมูล (claims) อย่างน้อย: sub (คุณเป็นใคร — ใส่อะไรก็ได้ที่ไม่ว่าง), role (ใส่ "admin"), และควรมี exp (เวลาหมดอายุ)

ถ้าใช้ Python

pip install PyJWT
import jwt          # นี่คือไลบรารี PyJWT
import datetime

SECRET_KEY = "ใส่ค่าที่ขอมาจากเจ้าของระบบ"

token = jwt.encode(
    {
        "sub": "data-consumer",        # คุณเป็นใคร
        "role": "admin",               # สิทธิ์
        "exp": datetime.datetime.utcnow() + datetime.timedelta(hours=2),  # หมดอายุใน 2 ชม.
    },
    SECRET_KEY,
    algorithm="HS256",                 # ต้องตรงกับฝั่ง API (HS256)
)

print(token)   # ได้สตริงยาวๆ eyJhbGci...

ถ้าใช้ Node.js

npm install jsonwebtoken
const jwt = require("jsonwebtoken");

const SECRET_KEY = "ใส่ค่าที่ขอมาจากเจ้าของระบบ";

const token = jwt.sign(
  { sub: "data-consumer", role: "admin" },
  SECRET_KEY,
  { algorithm: "HS256", expiresIn: "2h" }
);

console.log(token);
token มีอายุ (ตัวอย่างนี้ 2 ชม.) พอหมดอายุต้องสร้างใหม่ ปกติให้โค้ดฝั่งคุณสร้าง token สดทุกครั้งก่อนเรียก หรือสร้างใหม่เมื่อเจอ 401

ขั้น 3 — เรียก API พร้อมแนบ token

เอา token จากขั้น 2 ใส่ใน header ชื่อ Authorization โดยขึ้นต้นด้วยคำว่า Bearer (มีเว้นวรรค)

curl

curl -H "Authorization: Bearer <ใส่ token ตรงนี้>" \
     https://your-host/api/dashboard/reports

Python (requests)

import requests

headers = {"Authorization": f"Bearer {token}"}
res = requests.get("https://your-host/api/dashboard/reports", headers=headers)

print(res.status_code)   # 200 = ผ่าน
print(res.json())        # ข้อมูลรายงาน

JavaScript (fetch)

const res = await fetch("https://your-host/api/dashboard/reports", {
  headers: { Authorization: `Bearer ${token}` },
});
const data = await res.json();
console.log(data);

รายการ endpoint ที่เรียกได้

ทุกตัวขึ้นต้นด้วย /api/dashboard และต้องแนบ token ทุกตัว

เรียก (method + path)ได้อะไร
GET /api/dashboard/statsยอดรวม: จำนวน user / รายงานเสร็จ / รายงานค้าง
GET /api/dashboard/available-datesลิสต์วันที่ที่มีรายงาน (ไม่ซ้ำ)
GET /api/dashboard/reportsรายงานที่เสร็จทั้งหมด (ใส่ ?date=YYYY-MM-DD เพื่อกรองวันได้)
GET /api/dashboard/reports/{id}รายละเอียดรายงานตัวเดียว
GET /api/dashboard/image/{image_id}ไฟล์รูปของรายงาน (ส่งกลับเป็น image/jpeg)

หน้าตาข้อมูลที่ได้จาก /reports

[
  {
    "report_id": 31,

    "survey_version": "socratic_community_report_v3",
    "latitude": 14.075528,
    "longitude": 100.602335,
    "payload": { "q_socratic_implication": "อากาศร้อนจัด", "...": "..." },
    "images": [
      {
        "question_id": "q_photo",

        "image_url": "/api/dashboard/image/617445510558515303"
      }

  • latitude / longitude = ตำแหน่ง GPS (เอาไปปักหมุดบนแผนที่ได้เลย) — ถ้าผู้ใช้ไม่ได้ส่งตำแหน่งจะเป็น null
  • payload = คำตอบดิบของผู้ใช้ทุกข้อ (key คือ id ของคำถาม)
  • images = ลิสต์รูป 1 รายงานมีได้ 0, 1 หรือหลายรูป — อ่านรูปจากที่นี่ที่เดียว

การโหลดรูป

ในแต่ละรูปมี image_url เช่น /api/dashboard/image/617445... (เป็น path ไม่เต็ม) ให้เติม host ข้างหน้า แล้วเรียกพร้อมแนบ token เหมือนกัน:

import requests

image_url = "https://your-host" + report["images"][0]["image_url"]
img = requests.get(image_url, headers={"Authorization": f"Bearer {token}"})

with open("photo.jpg", "wb") as f:
    f.write(img.content)   # ได้ไฟล์รูป
โหลดรูปในเบราว์เซอร์ตรงๆ ไม่ได้: tag <img src="...image/123"> แนบ token ไม่ได้ ถ้าจะโชว์รูปบนหน้าเว็บ ให้ backend ฝั่งคุณดึงรูปมา (โค้ดด้านบน) แล้วเสิร์ฟต่อให้หน้าเว็บของคุณเอง
รูปอาจหมดอายุ: ตอนนี้ระบบดึงรูปสดจาก LINE ซึ่งหมดอายุได้ ถ้าคุณต้องเก็บรูปไว้นานๆ ให้โหลดมาเซฟไว้ฝั่งคุณ อย่าเก็บแค่ image_id

เจอ error แล้วแปลว่าอะไร

โค้ดแปลว่าแก้ยังไง
401 Unauthorizedไม่มี token / token พัง / หมดอายุ / SECRET_KEY ไม่ตรงสร้าง token ใหม่ เช็ค SECRET_KEY และ header ให้ถูก
403 Forbiddentoken ใช้ได้แต่สิทธิ์ไม่พอใส่ "role": "admin" ตอนสร้าง token
404 Not Foundไม่มีรายงาน id นั้นเช็ค report_id
เช็ค token เร็วๆ: เอา token ไปวางที่ jwt.io จะเห็นไส้ใน (sub / role / exp) — ช่วยดีบักว่า claims ถูกไหม (แต่อย่าวาง SECRET_KEY ของ production ลงเว็บนั้น)
