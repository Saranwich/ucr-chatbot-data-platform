# เฉพาะครั้งแรก

ขอสอบถามข้อมูลพื้นฐานเล็กน้อย เพื่อช่วยให้ทีมเข้าใจว่าข้อมูลที่แจ้งมาจากพื้นที่ใดและเกี่ยวข้องกับกลุ่มผู้ใช้แบบไหน ข้อมูลนี้ใช้เพื่อการวิเคราะห์ภาพรวมเท่านั้น และสามารถเลือก “ไม่สะดวกตอบ” ได้ทุกข้อ

**Q1. ท่านเกี่ยวข้องกับชุมชนใด**

* คนรักถิ่น  
* หลังแฟลต  
* ชุมชนอื่นในคลองเปรม  
* ไม่สะดวกตอบ / ไม่แน่ใจ

**Q2. ท่านเกี่ยวข้องกับพื้นที่นี้ในฐานะใด**

* ผู้อยู่อาศัย  
* ผู้เช่า  
* ผู้นำ/กรรมการชุมชน  
* คนทำงาน/ค้าขายในพื้นที่  
* ผู้ดูแลเด็ก/ผู้สูงอายุ/ผู้ป่วย  
* ผู้ใช้ทาง/คนเดินผ่าน  
* อื่น ๆ  
* ไม่สะดวกตอบ

**Q3. ช่วงอายุของท่าน**

* 18–30 ปี  
* 31–45 ปี  
* 46–59 ปี  
* 60 ปีขึ้นไป  
* ไม่สะดวกตอบ

**Q4. เพศของท่าน**

* หญิง  
* ชาย  
* อื่น ๆ / ไม่ระบุ  
* ไม่สะดวกตอบ

# Flow หลัก

วันนี้ต้องการแจ้งเรื่องใดคะ/ครับ

1. อากาศร้อนจัด  
2. น้ำท่วม / น้ำขัง

## **คำถามหลัก ใช้เหมือนกันทุกเรื่อง**

### **Q1. จุดที่เกิดปัญหาคือที่ไหน**

* พิมพ์ชื่อจุด / ซอย / บ้านใกล้เคียง  
* ส่งตำแหน่ง (แชร์ location)  
* ส่งรูป  
* อธิบายคร่าว ๆ

### **Q2. ปัญหานี้เกิดหรือกระทบช่วงเวลาไหน**

* เช้า  
* กลางวัน  
* บ่าย  
* เย็น  
* กลางคืน  
* ตอนฝนตก / หลังฝนตก  
* ไม่แน่นอน

### **Q3. โดยปกติเกิดนานประมาณเท่าไร**

* น้อยกว่า 1 ชั่วโมง  
* 1–3 ชั่วโมง  
* 4–6 ชั่วโมง  
* 8–12 ชั่วโมง  
* ข้ามวัน  
* ไม่แน่ใจ

### **Q4. ใครได้รับผลกระทบมากที่สุด**

* เด็ก  
* ผู้สูงอายุ  
* ผู้หญิง   
* ผู้ดูแล  
* ผู้ป่วย / ผู้พิการ  
* คนทำงาน / ค้าขาย  
* คนเดินผ่านทั่วไป  
* ทุกคน

### **Q5. กระทบอย่างไร**

เลือกได้ไม่เกิน 2 ข้อ

* อยู่ลำบาก / ต้องย้ายไปที่อื่น  
* เดินผ่านลำบาก  
* เข้าออกยาก  
* ไม่ปลอดภัย  
* ติดต่อสื่อสารไม่ได้  
* ชาร์จมือถือไม่ได้  
* ทำงาน / ค้าขายลำบาก  
* น้ำเข้าบ้าน  
* เด็ก / ผู้สูงอายุ / ผู้ป่วยได้รับผลกระทบ  
* อื่น ๆ

### **Q6. ถ้าตอนนี้ยังทำได้ไม่ครบทุกอย่าง ท่านคิดว่าควรเริ่มจากอะไร 3 อย่างแรก**

เลือกได้ไม่เกิน 3 ข้อ

* ร่มเงา / หลังคา / กันสาด  
* ที่นั่งพัก  
* ไฟส่องสว่าง  
* ติดพัดลม  
* ติดแอร์  
* จุดชาร์จมือถือ  
* Wi-Fi / ช่องทางสื่อสาร  
* ทางเดินที่ปลอดภัย  
* ปรับพื้น / ลดสิ่งกีดขวาง  
* พื้นที่รวมตัว / พื้นที่พักชั่วคราว  
* ตู้เย็นยา / ของจำเป็น  
* ยังไม่แน่ใจ

### **Q7. ความเร่งด่วนของเรื่องนี้**

* ด่วนมาก: กระทบความปลอดภัยหรือการเข้าออก  
* ปานกลาง: กระทบการใช้ชีวิต แต่ยังพอเลี่ยงได้  
* บันทึกไว้เป็นข้อมูลทั่วไป  
* ไม่แน่ใจ

## **คำถามเสริมเฉพาะบางกรณี**

ใช้เฉพาะเมื่อเลือกเรื่องนั้น ๆ

### **ถ้าเลือก “ร้อนมาก”**

**พื้นที่นี้เป็นพื้นที่แบบไหน**

* ในบ้าน  
* ทางเดิน  
* พื้นที่ส่วนกลาง  
* ศูนย์ชุมชน / บ้านกลาง  
* จุดนั่งพัก / จุดรอ  
* พื้นที่ทำงาน / ค้าขาย

**เวลาร้อนมาก ปกติรับมืออย่างไร**

* เปิดพัดลม  
* เปิดแอร์  
* ไปอยู่บริเวณที่ร่มอื่นรอบบ้าน  
* ไปพื้นที่ส่วนกลาง/บ้านญาติ  
* ไปเดินห้าง  
* เอามุ้งหรือผ้ามากางกันแดด  
* ทนอยู่ในบ้าน  
* อื่น ๆ

### **ถ้าเลือก “น้ำท่วม / น้ำขัง”**

**ระดับน้ำประมาณไหน**

* น้ำขังเล็กน้อย  
* ถึงข้อเท้า  
* ถึงหน้าแข้ง  
* ถึงเข่า  
* สูงกว่านั้น  
* ไม่แน่ใจ

**เวลาน้ำท่วม/น้ำขัง ปกติรับมืออย่างไร**

* เอาไม้พาดเพื่อเดินทางเข้าออก  
* ไปพื้นที่ส่วนกลาง/บ้านญาติ  
* อยู่ในบ้านเพราะออกไปไหนไม่ได้  
* อื่น ๆ
